About me

Welcome to my blog! I'm a security researcher passionate about threat modeling and automating stuff, with an interest in threat intelligence and malware analysis.


Why defensive security? I have always found fascinating how there is not a singular solution for monitoring, which creates endless scenarios and unique challenges. For example a new CVE, a new tool, a new attacker's methodology or the latest report from your red team. All of these sources bring us knowledge that we can use as learning opportunities to improve and develop new monitoring rules to detect these behaviours, the attack vectors used by the attackers.
